# GeekTool
GeekTool is a collection of practical tools and utilities built to improve developer productivity. It includes handy utilities for programming, debugging, encoding/decoding, cryptography, networking, data conversion, and other everyday tasks—all in one place.

## Run locally

Node.js 18 or newer is required.

```powershell
npm start
```

Open `http://localhost:3000`.

Included tools cover daily passwords, IP detection, encoding, hashes (MD5, SHA-1, SHA-256), 3DES, RSA public-key encryption, whitespace trimming, CAPA ECR analysis, and CapaService log checks for `"RESP":"CKE"`.
